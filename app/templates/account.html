pgmon can't reset a password by itself -- there's no "forgot password" flow, deliberately: doing it from inside the app would mean any admin session could silently take over any other account. Resetting requires a different, higher trust boundary instead.

  1. Pick a new password below, or click Generate.
  2. Click Copy command.
  3. Paste and run it in a terminal with kubectl access to this cluster.
  4. Have that person sign in with the new password (or you, if resetting your own).

At least 8 characters. Shown in plain text here since it's going straight into a command you'll run yourself.
