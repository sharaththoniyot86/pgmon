Forgot your password?

No self-service reset, by design — it would let any signed-in session take over another account. Run this where pgmon runs, then sign in above:

{% if deployment_mode == "container" %}

podman exec -it pgmon pgmon-reset-password <username>

docker works the same way. Creates the account if it doesn't exist.

{% elif deployment_mode == "standalone" %}

sudo pgmon-reset-password <username>

Needs root on the server pgmon runs on. Creates the account if it doesn't exist.

{% elif deployment_mode == "standalone-windows" %}

pgmon-reset-password.ps1 <username>

Needs an elevated PowerShell prompt. Creates the account if it doesn't exist.

{% else %}

kubectl exec -n {{ pgmon_namespace }} deployment/{{ pgmon_deployment }} -- python -m app.create_user <username> '<new-password>' --update

Needs kubectl access to this cluster. Already signed in as an admin? The Account page builds this command for you.

{% endif %}
